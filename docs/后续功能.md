# 后续功能清单（Backlog）

原则：**现在不做、写清触发条件再做**。每项记录成本估算与前置条件，避免反复讨论。

## 运维与后台

1. **运维 CLI + 运维手册（A 方案）** — 0.5 天
   - 内容：`cli ops sponsor-add/remove`、`pin/hide`、`category-override`、`stats`；`docs/运维手册.md`。
   - 触发：第一次要上推荐位，或要把站点交接给别人。
   - 备注：用户 2026-11-20 明确「放后续，先不做」。

2. **最小网页后台 `/admin`（B 方案）** — 1–2 天
   - 内容：GitHub OAuth 单一账号白名单；推荐位增删、插件隐藏/恢复、抓取看板；`audit_log` 表；CSRF + 限流。
   - 触发：经常不在电脑前，或已有付费推荐位客户。

3. **告警 webhook + `/ops` 只读页** — 0.5 天
   - 内容：Actions 失败、快照缺口、API 5xx 推送（邮件/飞书/Telegram）；聚合抓取健康度。
   - 触发：Actions 连续失败 2 天，或出现一次数据缺口事故。

## 数据与法务

4. **商标注册（第 42、35 类）** — 540–1500 元 + 8–10 个月
   - 触发：现在即可；先免费查近似，再决定自办/代理。
   - 备注：个人申请需个体户执照；保留使用证据（连续三年不使用可被撤销）。

5. **`data/snapshots` 私有化** — 0.5 天
   - 内容：快照提交到私有数据仓，站点只公开当日榜单与聚合数据；保留「公开可审计」改为「公开汇总 + 按需申请」。
   - 触发：出现整体抄袭站点，或首笔商业收入。

## 产品功能

6. **登录 + 押注 + 徽章（Phase 2）** — 3–5 天
   - 范围见 `设计文档.md` §4；ISO 周结算、积分账本、神射手榜。
   - 触发：周活 ≥ 300。

7. **周报 / 订阅提醒** — 1 天
   - 内容：每周 Top 涨速、自选插件变化、名单变更摘要；邮件或 RSS 增强。
   - 触发：订阅数 ≥ 100。

8. **含金量榜验证与品类动能** — 持续
   - 现状：已上线，等 ≥ 3 天有效快照后自动出数据。
   - 后续：品类动能（分类 star 增速）、异常流水页。

9. **跨源信号** — 2–3 天
   - 内容：npm 下载量、release 频率、issue 响应时长、DSH 市场安装量。
   - 触发：GitHub star 单维度不足以支撑差异化。

10. **英文界面 / i18n** — 1–2 天
    - 触发：非中文流量 > 20%。
